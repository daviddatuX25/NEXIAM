# NEXIAM System Context — Master Entry Point

Welcome to the **NEXIAM Technical Reference & System Context Package**.

This directory (`manuscript/system-context/`) contains the complete, self-contained documentation of NEXIAM's domain logic, system architecture, database schema, and reconciled vocabulary. It was created to allow researchers, advisers, and technical writers to complete the capstone manuscript outside this development environment with verified technical backing.
