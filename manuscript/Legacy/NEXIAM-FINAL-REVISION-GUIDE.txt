ISSUE 2.2 — TAM Item Non-Parallelism (Guidance PU Items 1-2)
-------------------------------------------------------------------------------
Table 3.2 (line 167-173):
  Pre Item 1: "I have the tools to profile applicants based on their
             exam performance."
  Post Item 1: "NEXIAM's decision-support triage helps me evaluate
              applicant readiness for placement."
  → These measure DIFFERENT activities. Pre asks about "tools to profile";
    Post asks about "evaluate readiness for placement."

  Pre Item 2: "The current process of reviewing exam scores is adequate
             for my counseling sessions."
  Post Item 2: "NEXIAM's triage output provides useful profiles for
              counseling sessions."
  → Pre asks about "reviewing exam scores"; Post asks about "triage
    output provides profiles." Different referent activities.

For a paired t-test to be valid, the pre and post items must measure the
same construct with only the referent changing (current process → NEXIAM).

ACTION: Either (a) reword pre-test items to describe the same activities
NEXIAM delivers (profiling, triage), or (b) add an explicit limitation
acknowledging that some TAM items necessarily measure different activities
because the manual process has no equivalent to automated triage.
