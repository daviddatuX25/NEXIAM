SCOPE

SCOPE AND LIMITATION

What NEXIAM Covers — And What It Doesn't

SCOPE

Admission testing workflow only — June to September 2026.

Seven user roles, full web-based application intake.

≥95% target OMR scoring accuracy.

RAG chatbot, K-Means aptitude dashboard (extensible ML model support), and AI-assisted scheduling — all active.

LIMITATION

No enrollment, tuition, or long-term records.

Cloud-hosted — proctoring interface alone keeps offline resilience via service-worker caching.

Free-tier OpenRouter inference caps request volume.

September evaluation uses proxy evaluators, not live applicants.

No formal NPC certification — protection is application-layer, not regulatory-certified.
