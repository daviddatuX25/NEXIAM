# Chapter 1: Introduction

## 1.6 Definition of Terms

To establish conceptual clarity throughout this manuscript, the following terms are defined operationally within the context of the study:

* **Admission Testing Pipeline:** The end-to-end institutional workflow governing applicant entry at ISPSC Tagudin Campus, encompassing public intake, document review, room-constrained examination scheduling, computer-vision scoring, decision support, result release, and enrollment eligibility verification.
* **Applicant Number and Reference Code:** An attributable, non-secret identification pair issued to an applicant upon application submission. In NEXIAM, it binds test booklets, answer sheets, consultation logs, and self-service portal sessions without exposing confidential credentials.
* **Course Triage:** An advisory decision-support process conducted during post-examination counseling wherein incoming student profiles are analyzed against curriculum benchmarks to estimate program fit, identify potential academic risks, and guide career advising.
* **HMAC-SHA256 Cryptographic Audit Trail:** A tamper-evident security mechanism that logs state-modifying actions into an append-only ledger. Each log entry incorporates a Hash-based Message Authentication Code generated using the SHA-256 cryptographic hash function, chaining each event to the previous record hash so that unauthorized alterations are mathematically detectable.
* **Ilocos Sur Polytechnic State College College Admission Test (ICAT):** The standardized entrance examination battery administered to incoming college applicants at ISPSC Tagudin Campus, comprising six cognitive and aptitude sub-tests: General Ability, Verbal Aptitude, Numerical Aptitude, Spatial Aptitude, Perceptual Aptitude, and Manual Dexterity.
* **In-Context Learning (ICL):** An inference paradigm where a pre-trained foundation model evaluates new query vectors against provided exemplar reference data in a single forward pass without modifying underlying model weights or requiring gradient updates.
* **Optical Mark Recognition (OMR):** A computer-vision technique that detects the presence and location of pencil or pen marks on standardized paper answer sheets by evaluating pixel fill densities relative to grid homography, automating the grading of multiple-choice tests.
* **Perceived Ease of Use (PEOU):** A Technology Acceptance Model construct defined operationally as the degree to which institutional personnel and student evaluators perceive interaction with the digital features of NEXIAM to be straightforward and free of cognitive effort.
* **Perceived Usefulness (PU):** A Technology Acceptance Model construct defined operationally as the degree to which evaluators believe that using NEXIAM enhances their administrative performance, reduces workflow delays, or clarifies their admission progress.
* **Proctor Duty Overlay:** A temporary, contextual authorization grant assigned to eligible Guidance or institutional staff, conferring room monitoring, roster attendance recording, and test submission capabilities for a specific examination session without altering the user's permanent organizational role.
* **Rapid Application Development (RAD):** A four-phase software engineering methodology comprising Requirements Planning, User Design, Rapid Construction, and Cutover, utilized in this study to translate empirical field findings into an integrated web platform through iterative prototyping and human code review.
* **Role-Based Access Control (RBAC):** An authorization security architecture that restricts system operations to authorized actors based on their organizational roles, departmental affiliations, and explicit capability assignments, enforcing data isolation under Republic Act No. 10173.
* **Slovin's Formula:** A statistical formula ($n = N / [1 + N(e)^2]$) used to calculate an adequate sample size from a finite population at a designated margin of error. In this study, it establishes the student evaluation sample of 255 participants from an estimated population of 700 applicants at a 0.05 margin of error.
* **TabPFN (Tabular Prior-data Fitted Networks):** A transformer-based tabular foundation model pre-trained on synthetic dataset distributions, used in NEXIAM to perform in-context Bayesian classification of applicant aptitude profiles against degree program benchmarks while natively handling missing secondary grades.
* **Technology Acceptance Model (TAM):** An information systems theoretical framework formulated by Davis (1989), administered in this study as a single post-test questionnaire to measure user acceptance across Perceived Usefulness and Perceived Ease of Use.
