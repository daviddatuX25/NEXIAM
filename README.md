# NEXIAM Capstone Manuscript & Portable System Context

This branch contains the standalone research manuscript drafts, research instruments, visual architecture models, and the reconciled system technical context for the NEXIAM capstone project (ISPSC Tagudin Campus).

## Structure

- `manuscript/sections/`: Canonical academic chapter drafts (Chapters 1, 2, 3, Appendices).
- `manuscript/system-context/`: Comprehensive, evidence-grounded technical reference (domains, terminology, workflows, claim crosswalks).
- `manuscript/SYSTEM_CONTEXT.md`: Master quick-start guide to the system context package.
- `manuscript/exports/`: TAM research questionnaires and institutional communication facsimiles.
- `manuscript/V2_RESOURCES/`: Diagrams, figures (D2/SVG/PNG), and visual architecture models.

## Ethics & Privacy Notice

All participant names from preliminary journey surveys have been sanitized and anonymized. All system accounts referenced are synthetic testing personas.
