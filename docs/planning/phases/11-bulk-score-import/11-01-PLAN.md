# Plan: Bulk Score Import - Backend

## Phase: E11 - Bulk Score Import
## Step: 01 - Backend Implementation

### Goal
Enable admin to import applicant scores via CSV/spreadsheet upload.

### Reference Patterns
- KnowledgeDocumentController CSV import
- ApplicantImportService (E10) - reusable parsing logic

### Database
- `applicant_scores` table exists
- Linked to `applicants` via `applicant_id`
- Has `grading_session_id` and score columns

### Steps

#### Step A: Create Import Request
Location: `app/Http/Requests/StoreScoreImportRequest.php`
- Extends FormRequest
- Validates: file (required|mimes:csv,xlsx,xls|max:10240)
- May include grading_session_id validation

#### Step B: Create Import Service
Location: `app/Services/ScoreImportService.php`
- Method: `parseCsv(File $file): array`
- Method: `validateScores(array $records, int $sessionId): ValidationResult`
- Method: `importScores(array $records, int $sessionId, User $importer): ImportResult`
- Reuses ApplicantImportService parsing logic

#### Step C: Add Routes
File: `routes/web.php`
```php
Route::get('grading/import', [ScoreImportController::class, 'importForm'])->name('grading.import');
Route::post('grading/import', [ScoreImportController::class, 'import'])->name('grading.import.store');
```

#### Step D: Create Controller
Location: `app/Http/Controllers/Grading/ScoreImportController.php`
- Method: `importForm()` - renders Import.svelte with grading sessions
- Method: `import(StoreScoreImportRequest $request)` - handles CSV processing

### CSV Format
- Required: `applicant_id` or `reference_number`
- Required: score columns (e.g., `raw_score`, `percentile`, `composite`)

### Acceptance Criteria
- [ ] CSV file upload accepts .csv, .xlsx, .xls
- [ ] Validates applicant exists in grading session
- [ ] Creates/updates ApplicantScore records
- [ ] Returns success/error summary to UI
- [ ] Authorized for admin roles only
