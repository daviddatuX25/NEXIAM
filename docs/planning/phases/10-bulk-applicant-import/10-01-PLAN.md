# Plan: Bulk Applicant Data Import - Backend

## Phase: E10 - Bulk Applicant Data Import
## Step: 01 - Backend Implementation

### Goal
Enable admin to import applicant records via CSV/spreadsheet upload.

### Reference Pattern
KnowledgeDocumentController CSV import:
- `app/Http/Controllers/Admin/KnowledgeDocumentController.php` (importForm, import methods)
- `app/Http/Requests/StoreCsvImportRequest.php`
- `app/Services/CsvToNarrativeService.php`

### Steps

#### Step A: Create Import Request
```bash
php artisan make:request StoreApplicantImportRequest
```

Location: `app/Http/Requests/StoreApplicantImportRequest.php`
- Extends FormRequest
- Validates: file (required|mimes:csv,xlsx,xls|max:10240)
- May include academic_year_id validation

#### Step B: Create Import Service
Location: `app/Services/ApplicantImportService.php`
- Method: `parseCsv(File $file): array`
- Method: `validateRecords(array $records): ValidationResult`
- Method: `importRecords(array $records, User $importer): ImportResult`
- Reusable: Can be extended for ApplicantScore import later

#### Step C: Add Routes
File: `routes/web.php`
```php
Route::get('applications/import', [ApplicationImportController::class, 'importForm'])->name('applications.import');
Route::post('applications/import', [ApplicationImportController::class, 'import'])->name('applications.import.store');
```

#### Step D: Create Controller
Location: `app/Http/Controllers/Admin/ApplicationImportController.php`
- Method: `importForm()` - renders Import.svelte
- Method: `import(StoreApplicantImportRequest $request)` - handles CSV processing
- Uses ApplicantImportService

### Database Considerations
- Applications table already exists (see schema)
- Need: reference_number generation, status defaults
- Consider: batch insert vs individual saves

### Dependencies
- AcademicYear model (existing)
- Course model (existing)
- User model (existing)

### Acceptance Criteria
- [ ] CSV file upload accepts .csv, .xlsx, .xls
- [ ] Validates required columns (name, email, course preferences)
- [ ] Creates Application records in database
- [ ] Returns success/error summary to UI
- [ ] Authorized for admin roles only
