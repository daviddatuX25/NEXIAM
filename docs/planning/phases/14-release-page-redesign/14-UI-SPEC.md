## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px (text-sm) | 400 (font-normal) | 1.5 (default) |
| Label | 12px (text-xs) | 400 (font-normal) + uppercase + tracking-wide | 1.5 (default) |
| Heading | 16px (text-base font-semibold) | 600 (font-semibold) | 1.3 (default) |
| Display | 20px (text-lg font-semibold) | 600 (font-semibold) | 1.3 (default) |

Notes:
- Two font weights declared: 400 (body, label) and 600 (heading, display).
- Labels for section dividers use `text-xs uppercase tracking-wide` — visual distinction via size + casing + letter-spacing, not weight.
- Body uses `text-sm` throughout the release page (matching existing Index.svelte).
- Page title handled by AuthenticatedLayout breadcrumbs, not declared here.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | --background (oklch(0.97 0.01 87.41)) | Page background, main surface |
| Secondary (30%) | --card / --card-solid (oklch(1 0 0 / 0.95)) | Cards, side panel, dialog content |
| Accent (10%) | --primary (oklch(0.52 0.13 144.33)) | Release All button, active tab indicator, Release button in side panel, tab trigger active state |
| Destructive | --destructive (oklch(0.54 0.19 26.90)) | Cancel/abort destructive actions, destructive confirmation modal text |

Accent reserved for: Release All primary CTA, active tab underline/indicator, Release button in side panel, selected checkbox accent ring.

Semantic overrides:
- **Success (released status)**: `--success` (oklch(0.62 0.15 142.90)) — used for released Badge variant
- **Warning (mode banner F2F)**: `--warning` (oklch(0.85 0.12 43.20)) — not currently used but available
- **Info (mode banner online)**: `--primary` with `/5` opacity for background, `/30` for border — matches existing pattern `border-primary/30 bg-primary/5`
- **Muted (draft/pending status)**: `--muted` / `--muted-foreground` — used for secondary Badge variant and disabled states

## Interaction Specifications

### Tab Switching (Both Mode)
- Two tabs: "Online" and "F2F"
- Default active tab: "Online"
- Each tab maintains its own dataset and pagination state independently
- Tab switch does not trigger a page reload — purely client-side state change
- Active tab uses `--primary` color for underline/indicator
- Inactive tab uses `--muted-foreground` color
- When mode is 'online' or 'f2f' (single mode), no tabs are rendered — show the relevant layout directly

### Release All Confirmation Dialog
- Triggered by "Release All" button click in online mode
- Dialog overlay: `bg-black/40` (matches existing Dialog pattern in research examples)
- Dialog content: `max-w-md`, centered, with border and shadow
- Shows dynamic count of unreleased summaries in the description
- "Proceed" button uses primary variant (default)
- "Don't Release" button uses outline variant
- Focus trap enabled (bits-ui AlertDialog handles this)
- Escape key closes the dialog
- Clicking overlay closes the dialog

### F2F Side Panel
- Existing pattern: fixed right-side panel, 384px wide (w-96), full height
- New addition: "Release" button appears below "Save Notes" button in the panel footer
- "Release" button only shown when `summary.status !== 'released'`
- Button order in panel footer: Save Notes (primary) > Release (primary) > Close (outline)
- On save failure: panel stays open, errors displayed
- On release failure: panel stays open, error displayed
- On release success: panel closes, table refreshes

### Mode Banners
- Existing pattern: `rounded-lg border` with semantic color variants
- Online: `border-primary/30 bg-primary/5` (blue-green tint)
- F2F: `border-border bg-muted/40` (neutral)
- Both: `border-border bg-muted/40` with updated wording

### Table Patterns
- Checkbox column width: `w-10` (40px)
- Cell padding: `px-4 py-3` (16px horizontal, 12px vertical)
- Header background: `bg-muted/50`
- Released rows: `opacity-60`
- Row actions: right-aligned, flex row with gap-2
