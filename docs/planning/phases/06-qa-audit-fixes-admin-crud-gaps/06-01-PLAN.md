### Task 3: Fix N+1 query in ExamSessionController::monitoring()

**Verification findings (checked codebase):**
- Lines 55, 465 already have `->with()` - COVERED
- Line 110: `whereHas('application')` on Applicant query - not an N+1 issue
- Lines 174, 229, 241, 258: `User::query()` - not ExamSession N+1
- Line 474: uses `->with()` from line 465 - COVERED

**Actual gap:** Line 590 in `monitoring()` method is MISSING eager loading:
```php
// monitoring() method around line 584 - NEEDS FIX:
$query = ExamSession::query()  // <- MISSING ->with()
    ->whereHas('proctors', fn ($q) => $q->where('users.id', $user->id));
```

**Fix:** Add `->with(['room:id,name,building,capacity', 'proctors:id,name', 'academicYear:id,academic_year,semester'])` before line 590.

**Verify:** `php artisan test --filter=ExamSessionControllerTest`

**Done when:** ExamSessionController::monitoring() includes eager loading

The 4 occurrences of empty return should either throw exceptions or return typed error responses with metadata explaining why data is unavailable.

**Verify:** `php artisan test --filter=DashboardServiceTest`

**Done when:** DashboardService returns typed responses with error context instead of empty returns
