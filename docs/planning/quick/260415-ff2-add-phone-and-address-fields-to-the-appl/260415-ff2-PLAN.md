## Plan

### Task 1: Add phone and address fields to Apply.svelte UI

The form data already contains `phone`, `address_line`, `city`, `province`, `zip_code` but the UI doesn't render them. Add a "Contact Information" section between sex and course preferences.

**Files:**
- `resources/js/Pages/Applications/Apply.svelte`

**Action:**
Add a `<details>` collapsible or a titled section "Contact Information" after the sex fields (before course preferences) containing:
- Phone input (bind to `$form.phone`)
- Address line input (bind to `$form.address_line`)
- City input (bind to `$form.city`)
- Province input (bind to `$form.province`)
- Zip code input (bind to `$form.zip_code`)

Group in a `<div class="grid gap-4 sm:grid-cols-2">` grid layout.

**Verify:**
- Fields render on the apply page
- Form submission includes these fields

### Task 2: Add terms and conditions checkbox

Add a terms checkbox that must be checked before the form can submit.

**Files:**
- `resources/js/Pages/Applications/Apply.svelte`

**Action:**
1. Add `terms_accepted: false` to the form data
2. Add a checkbox with label linking to terms/policy (can be a dummy href like `#`)
3. The checkbox must be `required` or validated in `onsubmit`
4. Disable submit button if `terms_accepted` is false

**Verify:**
- Checkbox renders
- Submit is disabled when unchecked
- Submit works when checked
