# Design: Repository Context Cleanup & CTXPKG Packaging

## Overview
This document outlines the strategy for cleaning up build-up and duplicate files generated by various AI agents, while capturing and packaging important project-specific guidelines, workflows, and conventions into a standardized, versioned, and portable **`.ctxpkg`** context package.

---

## 2. Approach: Packing Before Pruning
Rather than simply deleting directories, we will:
1. Extract the core conventions, guidelines, and rules from `.agents/skills/`, `.superpowers/`, and `AGENTS.md`.
2. Save them as structured **Knowledge** inside `lean-ctx`.
3. Export them to a portable context package: **`securecat-conventions.ctxpkg`**.
4. Prune the bloat directories and add them to `.gitignore` to prevent future tracking.

---

## 3. Context Package Structure (`securecat-conventions.ctxpkg`)
The package will contain the following layers:

### A. Knowledge Layer (`knowledge`)
*   **`laravel-best-practices`**: Laravel 12 development patterns (PHP 8 promotion constructors, Eloquent query performance, controllers).
*   **`tailwindcss-development`**: Tailwind v4 styling guidelines, responsive grids, UI styling patterns.
*   **`inertia-svelte-development`**: Svelte 5 + Inertia v2 integrations (Link/Form handling, deferred props).
*   **`frontend-design`**: Premium UI aesthetics tokens, font scaling, micro-animations.
*   **`core-workflows`**: Superpowers/Antigravity instructions (single-flow execution, verification before completion).
*   **`beads-commands`**: Quick reference for tracking tasks using `bd`.

### B. Graph Layer (`graph`)
*   Codebase relationship index (generated automatically by `lean-ctx graph build`).

---

## 4. Execution Steps

### Step 1: Initialize central rules
We already initialized `.lean-ctx/rules.toml` from the existing rules and synced them across agents.

### Step 2: Extract & Register Knowledge Facts
We will run a script to parse the key skills and register them as facts. E.g.:
```bash
lean-ctx knowledge remember "Always use PHP 8 constructor property promotion for dependency injection in Laravel 12." --category laravel-12 --key constructors
lean-ctx knowledge remember "When using deferred props in Inertia v2, always add an animated skeleton loader." --category inertia-svelte --key deferred-props
```

### Step 3: Build Graph & Create Package
We will rebuild the graph and generate the package:
```bash
npx lean-ctx graph build
npx lean-ctx pack create --name securecat-conventions
npx lean-ctx pack export securecat-conventions
```

### Step 4: Cleanup & Git Updates
Once the package `securecat-conventions-1.0.0.ctxpkg` is created:
1. Delete `.claude/worktrees/`.
2. Delete `.playwright-mcp/` and `.superpowers/`.
3. Move `.planning/` to `docs/archive/planning/`.
4. Update `.gitignore` to exclude temporary files:
   ```gitignore
   .claude/worktrees/
   .playwright-mcp/
   .superpowers/
   ```
5. Remove tracked copies of temporary folders from git:
   ```bash
   git rm -r --cached .playwright-mcp .superpowers
   ```
