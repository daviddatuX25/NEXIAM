## Widget Specification

### Floating Button (Collapsed State)
- Position: fixed, bottom-right, 24px from edges
- Size: 56px x 56px (touch-friendly)
- Icon: MessageSquare (lucide-svelte)
- Background: `--primary`
- Foreground: `--primary-foreground`
- Shadow: `shadow-lg` (from app.css --shadow-lg)
- Border-radius: 9999px (fully rounded)
- z-index: 50 (above normal content)

### Chat Panel (Expanded State)
- Position: fixed, bottom-right, 24px from edges
- Size: 380px width, max-height 520px
- Background: `--card` with glass effect
- Border: 1px solid `--border`
- Border-radius: 12px (lg radius)
- Shadow: `shadow-xl`

### Panel Sections
1. **Header** (48px height)
   - Title: "Chat with advisor" (16px, font-semibold)
   - Right side: close button (X icon), clear history button (trash icon)
   - Background: `--card`

2. **Messages Area** (flex-1, scrollable)
   - Min-height: 280px
   - Max-height: 360px
   - Padding: 12px
   - Background: `--muted/30` (from ScheduleAssistantPanel pattern)
   - Message bubbles: user right-aligned (primary bg), assistant left-aligned (muted bg)

3. **Input Area** (60px height)
   - Textarea: rows=2, placeholder="Type your question..."
   - Send button: primary variant, 44px height
   - Character counter: "Max 2000 characters" (12px, muted)

### Animations
- Expand/collapse: 200ms ease-out
- Message appear: 150ms fade-in
- Button hover: scale(1.05) 100ms
