### Chat Logic

#### send() function
```
1. text = input.trim(); if (!text || loading) return
2. input = ''; error = ''; messages = [...messages, {role: 'user', content: text}]; loading = true
3. fetch POST /portal/ai-companion/chat with headers (Content-Type: application/json, Accept: application/json, X-CSRF-TOKEN: csrf_token, X-Requested-With: XMLHttpRequest), body: JSON.stringify({message: text}), credentials: same-origin
4. If !res.ok: error = data.message ?? 'Something went wrong. Please try again.'; remove user message from messages
5. If data.reply: messages = [...messages, {role: 'assistant', content: data.reply}]
6. On catch: error = 'Network error. Please try again.'; remove user message from messages
7. finally: loading = false
```

#### clearHistory() function
```
1. Set clearing = true
2. fetch POST /portal/ai-companion/clear-history with headers (Content-Type: application/json, Accept: application/json, X-CSRF-TOKEN: csrf_token, X-Requested-With: XMLHttpRequest), credentials: same-origin
3. If res.ok: messages = []
4. finally: clearing = false
```
