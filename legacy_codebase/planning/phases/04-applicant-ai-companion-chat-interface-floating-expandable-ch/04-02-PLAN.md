```svelte
// Component accepts props:

  ai_companion_enabled = false,  // true = system enabled + consultation released
  csrf_token = '',               // from $page.props.csrf_token
  initialMessages = [],          // pre-loaded chat history
} = $props();
```

## Backend Integration Points (from AiCompanionController.php)

1. Backend already checks `SystemSetting::aiCompanionEnabled()` and consultation status before enabling
2. Backend passes `ai_companion_enabled` via dashboard/page props — we need to pass this to the layout
3. CSRF token available via `csrf_token()` PHP function

## Integration Pattern

The widget should be:
- Conditionally rendered only when `ai_companion_enabled` is true
- Passed `csrf_token` from page props
- Passed `initialMessages` as empty array (widget fetches history on first use — OR pass from parent if available)
- Persisted in DOM across page navigation (stays mounted in layout, not in page components)

## What needs to change in PortalLayout.svelte

1. Import AiCompanionChatWidget: `import AiCompanionChatWidget from '@/Components/AiCompanionChatWidget.svelte';`
2. Derive `ai_companion_enabled` from page props: `$derived($page.props.ai_companion_enabled ?? false)` — note: this prop must be passed by the backend from PortalAuthController dashboard response
3. Derive `csrf_token` from page props: `$derived($page.props.csrf_token ?? '')`
4. Render widget AFTER the main content (so it's on top): add `<AiCompanionChatWidget ai_companion_enabled={ai_companion_enabled} csrf_token={csrf_token} />` at the end of the layout, before or inside the closing div

## Important Note on Backend Props

The RESEARCH.md mentions `ai_companion_enabled` is passed from `PortalAuthController` (line 292). If this prop does NOT exist yet in the backend dashboard response, this plan will need a companion backend change to pass the prop. For now, check the existing props and use `$page.props.ai_companion_enabled ?? false` as a safe fallback.

3. **Add widget render** at the end of the layout's main div (just before the closing `</div>` of `class="min-h-screen flex flex-col"`):
```svelte

We can simplify by just rendering the widget and letting the widget check its own `ai_companion_enabled` prop — so the conditional here can be removed if preferred. However, keeping it avoids unnecessary component instantiation.
