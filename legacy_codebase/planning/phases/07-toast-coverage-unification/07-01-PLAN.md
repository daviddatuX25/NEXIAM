# Phase 07-01: Toast Coverage Unification

**Objective:** Replace inline error/success panels with toast notifications throughout the application while preserving per-input field errors.

## Context

The application currently uses multiple message patterns:

1. **ToastManager** already handles Laravel flash messages globally (`session->with('success')`, `session->with('error')`)
2. **Inline panels** with `bg-destructive/10` or `bg-primary/10` are rendered in many pages (DUPLICATES)
3. **Per-input field errors** (must remain as-is)
4. **Hardcoded inline messages** like "Exam window ended. Actions locked." (ugly, should use toasts)

## Architecture

### Current Flow
```
Controller: session()->with('error', 'message')  →  ToastManager (page.subscribe)  →  toasts[]
```

### Problem
1. ToastManager shows toast
2. Page ALSO renders inline panel with same message
3. Duplicate!

### Solution
1. Remove inline flash panels from pages (they're redundant)
2. Convert hardcoded messages to toast triggers
3. Keep per-field errors
