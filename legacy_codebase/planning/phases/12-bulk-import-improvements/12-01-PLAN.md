# Plan: Bulk Import UX Improvements - 2-Step Import Flow

## Phase: E12 - Bulk Import UX Improvements
## Step: 01 - Two-Step Import Implementation

### Goal
Enhance bulk import with column mapping, preview, and selective import capabilities.

### Current Issues
- Hardcoded column names (user must use exact headers)
- No preview - all or nothing import
- No validation flags in UI

### New Flow
1. **Step 1:** Upload + Parse + Validate → Show Preview
2. **Step 2:** User confirms → Import valid rows only

### Steps

#### Step A: Add Preview Data to Service
Location: `app/Services/ApplicantImportService.php`
- Add method: `getPreview(array $records, int $limit = 20): array`
- Returns parsed records with validation status per row
- Include row number, data, errors (if any)

#### Step B: Update Controller for 2-Step Flow
Location: `app/Http/Controllers/Admin/ApplicationImportController.php`
- Method: `preview(StoreApplicantImportRequest $request)` - returns parsed data as Inertia page
- Method: `importConfirmed(...)` - actually imports after preview confirmation

#### Step C: Add Preview Route
File: `routes/web.php`
```php
Route::post('/applications/import/preview', ...)->name('applications.import.preview');
Route::post('/applications/import/confirm', ...)->name('applications.import.confirm');
```

#### Step D: Create Preview Svelte Page
Location: `resources/js/Pages/Admin/Applications/ImportPreview.svelte`
- Show table of parsed records
- Show validation errors inline (red highlight)
- Checkbox to include/exclude rows
- "Import Selected" button

### CSV Column Mapping (Optional Enhancement)
- For Phase 2: Allow mapping columns to fields
- For now: Document required headers, fail gracefully

### Acceptance Criteria
- [ ] Upload shows preview table with first 20 records
- [ ] Invalid rows highlighted in red
- [ ] Valid rows shown in green/normal
- [ ] Can deselect rows to skip
- [ ] Import only selected rows
- [ ] Show count imported vs skipped
- [ ] Same improvements for Score Import
