# Phase 3 Plan: Toast Feedback for Admin Create/Edit Pages

## Overview
Add success toast notifications to all admin create and edit form submissions using Inertia's `onSuccess` callback on `useForm`. Phase 2 toast system provides `success(message)` that auto-dismisses after 4 seconds with a chime sound.

## Requirements
- T3-01: Toast appears on successful create action
- T3-02: Toast appears on successful edit/update action
- T3-03: Toast shows appropriate message ("Academic Year created", "Room updated", etc.)
- T3-04: Toast appears on error (optional, nice-to-have)

## Example Changes

### AcademicYears/Create.svelte
```svelte
<script>
  import AuthenticatedLayout from '@/Layouts/AuthenticatedLayout.svelte';
  import { Link, useForm } from '@inertiajs/svelte';
  import { Button } from '@/Components/ui/button';
  import { Input } from '@/Components/ui/input';
  import { success } from '@/lib/toast';

  const form = useForm({
    academic_year: '',
    semester: '',
    application_start_date: '',
    application_end_date: '',
  });

  $form.onSuccess = () => success('Academic year created');

  function submitForm(e) {
    e.preventDefault();
    $form.post('/admin/academic-years');
  }
  const breadcrumbs = [{ label: 'Academic Years', href: '/admin/academic-years' }, { label: 'Create' }];
</script>
```

### Rooms/EditForm.svelte
```svelte
<script>
  import { Link, useForm, router } from '@inertiajs/svelte';
  import { Button } from '@/Components/ui/button';
  import { Input } from '@/Components/ui/input';
  import Switch from '@/Components/ui/switch/switch.svelte';
  import { success } from '@/lib/toast';

  let { room } = $props();

  const form = useForm({
    name: room?.name ?? '',
    building: room?.building ?? '',
    floor: room?.floor ?? '',
    capacity: String(room?.capacity ?? ''),
    is_active: room?.is_active ?? true,
  });

  $form.onSuccess = () => success('Room updated');

  function submitForm(e) {
    e.preventDefault();
    $form.transform((data) => ({
      ...data,
      capacity: parseInt(data.capacity, 10),
    }));
    $form.put(`/admin/rooms/${room.id}`);
  }
  // ...
</script>
```

## Testing Strategy
Manual verification:
1. Open each create page, submit valid form, confirm toast appears top-right with correct message
2. Open each edit page, submit valid form, confirm toast appears top-right with correct message
3. Confirm toast auto-dismisses after 4 seconds
4. Confirm error submissions do NOT trigger success toast

## Success Criteria
- [ ] All 9 create pages show toast with entity-appropriate message
- [ ] All 9 edit pages show toast with entity-appropriate message

- [ ] Toast appears at top-right position
- [ ] No console errors on form submission
